# Google Mobile Ads SDK for Android (legacy)

> [!CAUTION]
> This repository has developer samples and snippets for the legacy Google
Mobile Ads SDK (`com.google.android.gms:play-services-ads`). Use the
[GMA Next-Gen SDK](https://github.com/googleads/gma-next-gen-sdk-android-examples)
(`com.google.android.libraries.ads.mobile.sdk:ads-mobile-sdk`) for the latest
samples and snippets.
